## Typography

### Font Families

#### Headings (H1, H2, H3, H4, H5, H6)
- **Font:** Inter Bold
- **Weight:** 700
- **Line Height:** 1.2
- **Letter Spacing:** -0.01em
- **Usage:** Page titles, section headers, CTAs

#### Body Text
- **Font:** Inter Regular
- **Weight:** 400
- **Size:** 16px
- **Line Height:** 1.6
- **Letter Spacing:** 0em
- **Usage:** Paragraph text, descriptions, content

#### Code/Technical
- **Font:** Roboto Mono
- **Weight:** 400
- **Size:** 14px
- **Usage:** Code blocks, technical content, API docs

### Font Sizes

```
H1: 48px / 3rem (Display)
H2: 36px / 2.25rem (Large heading)
H3: 28px / 1.75rem (Medium heading)

H6: 16px / 1rem (Smallest heading)
Body: 16px / 1rem
Small: 14px / 0.875rem
Tiny: 12px / 0.75rem
```

## Dos and Don'ts

### ✅ Do
- Use brand colors consistently
- Maintain sufficient spacing
- Use approved typography
- Keep logos clear and readable
- Use proper contrast ratios

### ❌ Don't
- Stretch or distort logos
- Use unauthorized colors
- Mix font families unnecessarily
- Reduce logo size below 64px
- Use low contrast text
